# OpenSCWL

**Open SimCity Without Limits**
OpenSCWL is currently in active development and is not yet ready for public use, nor will have any updates to this repository until the private research phase is finished.

## Our Mission
OpenSCWL is an open-source preservation project aiming to create a fully independent, self-hosted multiplayer backend for SimCity (2013).
Our goal is to ensure SimCity remains playable long after EA's official servers eventually shut down, while laying the groundwork for future multiplayer modding and community development.
